## DevVault | Professional AI & Full-Stack Portfolio
Welcome to the repository of DevVault, a modern, multipage portfolio website designed to showcase high-end web development and AI-driven projects. This application features a clean, professional aesthetic with interactive components built using React and Material UI.

## 🚀 Overview
DevVault is more than just a portfolio; it is an experiment in modern UI/UX design. It utilizes a sophisticated "voxel-style" tech aesthetic, integrating advanced Material UI components like expandable cards, custom themes, and a dynamic rating system to provide an engaging user experience.

## ✨ Key Features
1. Multipage Architecture: Seamless navigation between Home, Projects, and Contact pages using react-router-dom.
2. Interactive Hero Section: Features a high-resolution voxel city avatar and smooth scroll-to-content transitions.
3. Expandable Project Cards: Projects are displayed using an advanced RecipeReviewCard layout, allowing users to "deep-dive" into technical details through animated dropdowns
4. Custom Rating System: An interactive feedback component in the Contact section with hover effects and dynamic labels.
5. Modern Theming: A professional color palette utilizing Deep Navy Blue, Cloud White, and Accent Blue (#007bff) for high contrast and readability.
6. Fully Responsive: Optimized for all screen sizes, from mobile devices to large desktop monitors.

## 🛠️ Tech Stack
**Frontend Library:** React.js
**UI Framework:** Material UI (MUI)
**Styling:** CSS3, Bootstrap (Utilities), and MUI System
**Routing:** React Router v6
**Icons:** MUI Icons & Star Icons

## 📂 Project Structure
```bash
src/
├── components/       # Reusable UI elements (Navbar, Footer, ProjectCard, ReviewCard)
├── pages/            # Page-level components (Home, Projects, Contact)
├── assets/           # Images, avatars, and static files
├── App.jsx           # Main routing and ThemeProvider setup
├── index.css         # Global styles and Tailwind/Bootstrap imports
└── main.jsx          # Application entry point
```
